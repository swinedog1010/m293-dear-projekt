## 📖 Über das Projekt
D.E.A.R. ist eine innovative Plattform, die als Startup-Projekt für das Modul 293 (Webauftritt erstellen) am TBZ entwickelt wird. Die Grundidee: Lernende stellen spannende Bücher in Form von kurzen, knackigen Podcasts vor. Ziel ist es, Jugendliche wieder mehr fürs Lesen zu begeistern, indem Buchvorstellungen digital, modern und auditiv erlebbar gemacht werden.

## ✨ Features der Webseite
* **Responsive Design:** Perfekte und flüssige Darstellung auf Mobile, Tablet und Desktop.
* **Podcast-Grid:** Übersichtliche Kacheln für jede Buchvorstellung im modernen 9:16 Cover-Format.
* **Kategorien-Filter:** Schnelle Suche nach Genres wie Krimi, Fantasy oder Sachbuch.
* **Audio-Integration:** Detailseiten mit integriertem Audio-Player für die Podcasts.
* **Newsletter & Kontakt:** Integrierte Formulare für interessierte Zuhörer.

## 📂 Projektstruktur
Das Repository ist in zwei übersichtliche Hauptbereiche unterteilt:

* `/Code` - Enthält den lauffähigen HTML- und CSS-Code der finalen Webseite.
  * `index.html` (Startseite mit Hero-Bereich und Highlights)
  * `buecher.html` (Übersicht aller Podcasts & Filter)
  * `detail.html` (Vorlage für den Podcast-Player & Infos)
  * `about.html` (Projektinfos & Kontaktformular)
  * `/css/style.css` (100% eigenes Styling, Custom Variables, CSS Grid & Flexbox)
* `/docs` - Enthält alle Planungs- und Dokumentationsunterlagen.
  * `styleguide.md` (Definition von Farben & Typografie)
  * `wireframes.md` (Layout-Skizzen für Mobile, Tablet, PC)
  * `nutzwertanalyse.md` (Evaluation der Entwicklungsumgebung)

## 🛠️ Verwendete Technologien
* **Struktur:** Semantisches HTML5
* **Design:** CSS3 (ohne externe Frameworks wie Bootstrap)
* **Schriften:** Google Fonts (Poppins für Überschriften, Inter für Fliesstext)
* **Versionsverwaltung:** Git & GitHub
* **Code-Editor:** Visual Studio Code
* **Planung:** Miro (Wireframing)

## 🚀 Lokales Setup
Um das Projekt lokal auf deinem Rechner auszuführen:
1. Repository klonen: `git clone https://github.com/swinedog1010/m293-dear-projekt.git`
2. Den Projektordner in Visual Studio Code öffnen.
3. Die Datei `/Code/index.html` mit der VS Code Erweiterung "Live Server" starten oder direkt im Browser öffnen.
