# Nutzwertanalyse: KI-Entwicklungsassistent

Für die effiziente Programmierung des D.E.A.R. Projekts (HTML/CSS) soll ein moderner KI-Assistent eingesetzt werden. Als Lernender bei der Opten AG ist es wichtig, Tools zu evaluieren, die den Agentur-Alltag beschleunigen, aber gleichzeitig einen sauberen Lernprozess garantieren. Zur Auswahl stehen die beiden aktuell führenden KI-Lösungen.

## 1. Zur Auswahl stehende Tools
* **Option A:** GitHub Copilot (als Plugin in Visual Studio Code)
* **Option B:** Cursor (Ein eigenständiger Editor-Fork von VS Code mit integrierter KI)

## 2. Bewertungskriterien und Gewichtung
Die Kriterien werden mit einer Gewichtung (1 = nice-to-have, 3 = essenziell) versehen. Die Bewertung erfolgt auf einer Skala von 1 (sehr schlecht) bis 5 (sehr gut).

1. **Integration in den Workflow (Gewichtung: 3):** Wie gut lässt sich das Tool in bestehende Arbeitsabläufe integrieren? VS Code ist der Standard, ein kompletter Wechsel der Entwicklungsumgebung ist eine Hürde.
2. **Kosten für Lernende (Gewichtung: 3):** Das Tool sollte für ein Schulprojekt und für Auszubildende idealerweise kostenlos zugänglich sein.
3. **KI-Funktionen & Code-Verständnis (Gewichtung: 3):** Autovervollständigung, Chat-Funktion und das Verständnis für das gesamte Projekt (HTML + CSS Verknüpfung).
4. **Datenschutz & Industrie-Standard (Gewichtung: 2):** Ist das Tool in der professionellen Webentwicklung etabliert und vertrauenswürdig?

## 3. Bewertung (Punkte x Gewichtung)

| Kriterium | Gewichtung | GitHub Copilot (A) | Cursor (B) |
| :--- | :---: | :---: | :---: |
| Workflow-Integration | 3 | 5 (15) | 3 (9) |
| Kosten | 3 | 4 (12)* | 3 (9)** |
| KI-Funktionen | 3 | 4 (12) | 5 (15) |
| Industrie-Standard | 2 | 5 (10) | 3 (6) |
| **Total** | | **49** | **39** |

*\*Kostenlos über das GitHub Student Developer Pack.*
*\*\*Hat eine kostenlose Version, aber mit stark limitierten Premium-KI-Anfragen.*

## 4. Fazit und Entscheidung
Der Sieger dieser Analyse ist **GitHub Copilot** mit 49 Punkten. 

Obwohl Cursor bei den reinen KI-Features (wie dem Verstehen des gesamten Projekt-Kontextes) extrem stark ist, gewinnt Copilot durch die nahtlose Integration. Da Copilot als Plugin direkt im ohnehin genutzten VS Code läuft, muss die Entwicklungsumgebung nicht gewechselt werden. Zudem ist es der absolute Industrie-Standard, den man als angehender Applikationsentwickler beherrschen sollte, und für Lernende über GitHub Education komplett kostenlos. Daher wird Copilot für das D.E.A.R. Projekt gewählt.
