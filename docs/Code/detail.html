Krimi

Der Schatten im Netz

von Max Mustermann

Dauer 5:12 Min
Kategorie Krimi
Erschienen 2025

Jetzt reinhören

Darum geht's

Stell dir vor, dein gesamtes digitales Leben verschwindet von einer Sekunde auf die andere. In diesem spannenden Krimi geht es um einen jungen Programmierer, der plötzlich feststellen muss, dass er nicht mehr existiert – keine Bankkonten, keine Social-Media-Profile, keine digitale Identität. Auf der Suche nach dem Hacker, der sein Leben ausgelöscht hat, stösst er auf ein internationales Netzwerk, das weit gefährlicher ist als erwartet.

Ein packender IT-Thriller, der zeigt, wie verletzlich unser digitales Ich wirklich ist – und warum Cybersecurity uns alle betrifft.
